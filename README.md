# Sistema Web de Gestão de Tarefas

Projeto inicial desenvolvido para a disciplina de **Laboratório de Programação Back End**, estruturado em **Python** utilizando o framework **Django** para a organização de tarefas.

## 📌 Objetivo Resumido

Configurar a estrutura inicial do projeto backend em Python, estabelecendo o isolamento de dependências com ambiente virtual e versionamento correto via Git, além de estruturar o projeto Django com separação de responsabilidades (projeto e aplicação) e implementar rotas, views e templates HTML dinâmicos. O projeto está dividido em pastas com o nome das aulas. Na pasta raíz do repositório está referente a aula 6 onde foi feito implementação do Django

## 🛠️ Pré-requisitos e Tecnologias

* **Python 3** instalado
* **Django**
* **VS Code** (Editor e terminal integrado)
* **HTML5 & CSS3** 

## 🚀 Execução

1. **Abra a pasta do projeto:** Abra a pasta raiz do projeto no seu ambiente de desenvolvimento.
2. **Crie o ambiente virtual:** `python -m venv .venv`
3. **Ative o ambiente virtual:** `.venv\Scripts\activate` (ou `.venv\Scripts\Activate.ps1` no PowerShell)
4. **Instale as dependências requirements.txt**: `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`
5. **Execute o servidor:** `python manage.py runserver`
